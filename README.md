# Project001

## Goal

Create a relaxing mobile puzzle game for iOS and Android.

Business goal:
Build a polished MVP that can generate revenue through rewarded ads and ad removal purchase.

Engine:
Unity 6

Language:
C#

Platforms:
- iOS
- Android

Repository status:
Project initialized.

---

## Development principles

- Ship fast.
- Build quality foundations.
- Keep gameplay simple.
- Avoid premature optimization.
- Every feature should answer the question:
  "Will this help us earn money sooner?"

---

## Development workflow

- Small iterative tasks
- Code review before merge
- Git for version control
- Documentation before implementation
