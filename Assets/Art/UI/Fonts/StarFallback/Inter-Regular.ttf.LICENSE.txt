Used solely as a narrow TMP fallback font asset (see
StarFallbackFontAssetBuilder.cs) so TextMeshPro can render the single ★
(U+2605) glyph the Fredoka font files do not include, for the Level
Complete modal's decorative separator accent. Not used as a primary
UI typeface anywhere in this project.
